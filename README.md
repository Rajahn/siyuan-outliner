# Outliner (SiYuan plugin)

A Mubu-style outliner for SiYuan, focused on fast keyboard-driven outlining.

- Enter / Tab / Shift+Tab, split & merge topics, Shift+Enter for notes, Ctrl+Enter to complete
- Ctrl+↑/↓ fold/unfold, Ctrl+Shift+↑/↓ move, Alt+→/← zoom in/out (or click a bullet)
- Multi-select with Shift+↑/↓ or mouse drag; drag bullets to reorder
- Paste multi-line text / Markdown lists as nested topics
- One-way sync of an outline into a SiYuan document; convert SiYuan docs/lists into outlines

Data lives in `data/storage/petal/siyuan-outliner/` as JSON and syncs with SiYuan. Desktop only.
