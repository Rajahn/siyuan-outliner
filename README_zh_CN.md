# 大纲（思源插件）

幕布风格的大纲编辑器，专注「列大纲、梳理思路」的手感。

## 安装

1. 把 `siyuan-outliner` 文件夹放到 `思源工作空间/data/plugins/` 下
2. 思源 → 设置 → 集市 → 已下载 → 插件，打开「大纲」的开关（若提示安全模式，先关闭安全模式）
3. 点顶栏左侧的大纲图标打开；也可以用命令面板或快捷键 `Alt+Ctrl+O`（mac 为 `⌥⌘O`，可在 设置 → 快捷键 里修改）

## 快捷键

带 ★ 的可以在「设置 → 快捷键」里修改（Ctrl+/ 查看当前设置）。

| 操作 | 默认快捷键 |
| --- | --- |
| 新建主题（光标在中间时拆分） | Enter |
| ★ 进入 / 退出换行模式（模式中 Enter 只在主题内换行） | Shift + Enter，Esc 也可退出 |
| ★ 添加 / 编辑描述 | Alt + Enter |
| 缩进 / 反缩进 | Tab / Shift + Tab |
| ★ 完成 / 取消完成 | Ctrl + Enter |
| ★ 折叠 / 展开 / 切换折叠 | Ctrl + ↑ / ↓，Ctrl + . |
| ★ 上移 / 下移主题 | Ctrl + Shift + ↑ / ↓ |
| ★ 进入主题 / 返回上一级 | Alt + → / ←，或点击圆点 |
| ★ 标题 | Ctrl + Alt + 1 / 2 / 3，Ctrl + Alt + 0 恢复正文 |
| ★ 删除线 / 链接 | Ctrl + Shift + X / Ctrl + K |
| ★ 搜索当前大纲 | Ctrl + F |
| 合并到上一个主题 | 行首 Backspace |
| 多选主题 | Shift + ↑ / ↓、鼠标跨行拖选、Esc |
| 复制 / 剪切 / 粘贴主题 | Ctrl + C / X / V |
| 加粗 / 斜体 / 下划线 | Ctrl + B / I / U |
| 撤销 / 重做 | Ctrl + Z / Ctrl + Shift + Z |
| 插入表格、代码块、公式、Mermaid 图、图片、链接 | 输入 / （中文输入法下的「、」也可以） |

## 标签、链接、搜索

- 在主题里写 `#标签`：点击标签筛选；在顶部搜索框输入 `#` 会列出本大纲的所有标签
- 右键圆点「复制主题链接」、左侧条目「复制大纲链接」：粘贴到思源笔记里，点击即可打开并定位到这个主题
- 主题里的思源块链接（`siyuan://blocks/…`）按住 Ctrl / ⌘ 点击可以直接打开
- 左侧搜索框同时搜索所有大纲的标题和内容（也支持 `#标签`），点击结果直接跳到对应主题

## 大纲列表

- 左侧顶部的两个按钮：新建文件夹、新建大纲
- 悬停条目时出现 `+`（在里面新建大纲）和 `⋯`（更多操作）；右键也能打开菜单
- 一篇大纲下面可以挂子大纲，文件夹里可以再建文件夹，层级不限
- 拖动条目：放在条目上半部 / 下半部是排到它前面 / 后面，放在中间是放进它里面
- 双击标题可以重命名；「移动到…」可以从列表里选择目标位置
- 删除文件夹或大纲时，里面的子项会一起删除（会先确认）

## 设置

左下角「设置」或「更多 → 设置」：页面宽度、字号、行距、层级竖线、自动同步的等待时长、自定义快捷键、回收站、清理未使用的图片。

## 数据安全

- 多个窗口（或多台设备同步）同时使用时会互相合并，不会把对方新建的内容覆盖掉；如果两边同时修改了同一篇大纲，另一边的版本会另存为「（另一窗口的版本）」副本，两边内容都保留
- 保存失败会在顶栏提示并自动重试
- 删除的大纲和文件夹先进回收站（左下角），保留 30 天
- 每篇大纲自动保留历史版本（编辑时每隔一小时一份；24 小时内全保留，更早的每天一份，保留 30 天），「更多 → 历史版本」可以查看和恢复
- 图片保存在插件自己的目录里，不会被思源「清理未引用资源」误删；同步到思源时才会复制一份到思源的 assets
- 「在独立新窗口打开」可以把一篇大纲放到单独的窗口里

## 数据

- 大纲保存在 `data/storage/petal/siyuan-outliner/`，每篇大纲一个 JSON 文件，会跟随思源同步
- 「同步到思源」是单向的：把大纲生成一篇思源文档（嵌套列表），以后再点会覆盖更新这篇文档。在思源里对这篇文档的修改不会回写到大纲
- 自动同步（默认开启，可在「更多」菜单关闭）：手动同步过一次的大纲，停止编辑约 30 秒后会自动同步；同一篇至少间隔 1 分钟，连续编辑时最多 2 分钟同步一次；切换大纲或关闭页签时会补同步一次；内容没变化时不会重写。同步按钮旁会显示同步状态
- 首次同步时，文档会按左侧的层级放置，例如「工作 / 周报」，文件夹和上级大纲会成为上级文档；之后在左侧移动位置，不会移动已经生成的思源文档
- 在思源文档标题菜单或块菜单中选择「转为大纲」，可以把已有的文档或列表变成一篇大纲

## 已知限制

- 只支持桌面端
- 暂不支持文件夹、标签、跨大纲全文搜索
- 公式和 Mermaid 图使用思源自带的 KaTeX、Mermaid 渲染；表格不支持合并单元格
